Tier 1 — Non-Negotiable Core

1. C++ Basics & Code Reading

  • Read C++ code and predict output line-by-line
  • Identify compile-time, runtime, and logic errors
  • Explain operator precedence in expressions
  • Know when implicit type conversion happens 
int x = 5;
double y = x / 2;
std::cout << y;

2. Functions & Parameter Passing

  • Write functions with correct signatures
  • Explain pass-by-value vs pass-by-reference
  • Use const T& appropriately
  • Know when a function can and cannot modify arguments
void f(const std::vector<int>& v);
    void g(std::vector<int>& v);

3. Control Flow

  • Write and trace if / else, for, while, do-while
  • Choose the correct loop type
  • Identify off-by-one errors

Tier 2 — Containers & Data Structures

4. std::vector

  • Declare, initialize, modify, and iterate
  • Explain [] vs .at()
  • Understand size() vs capacity() (conceptually)
  • Use range-based for loops
  • Explain iterator invalidation at a high level

5. Other Standard Containers

  • Use std::map and std::set
  • Explain key-value pairs, uniqueness, and ordering
  • Choose the correct container for a problem

6. Iterators

  • Use begin() / end()
  • Write loops using iterators
  • Understand what *it means
  • Recognize invalid iterator usage

Tier 3 — Algorithms & Modern C++

7. Standard Algorithms

  • Use find, count, sort, accumulate
  • Replace loops with algorithms
  • Explain algorithm intent

8. Lambdas

  • Write lambdas with parameters
  • Capture variables by value [x] and reference [&x]
  • Explain lambda lifetime
  • Use lambdas with algorithms

Tier 4 — Object-Oriented Programming

9. Structs, Classes & Encapsulation

  • Define struct and class
  • Explain public vs private
  • Write member functions
  • Use const member functions correctly

10. Constructors

  • Write constructors
  • Use initializer lists
  • Explain why initializer lists are preferred
  • Write multiple constructors
MyClass(int x) : value(x) {}

11. Operator Overloading

  • Overload ==, <, <<
  • Know when operators should be free functions
  • Use const correctly

Final Reality Check

  • Trace code without running it
  • Explain why something is wrong, not just fix it
  • Recognize container and algorithm patterns
  • Reason instead of memorizing
