Question 1 [6 marks]

Consider the syntactically correct C++ code below. 

#include <iostream>
#include <string>
#include <vector>
#include <utility>

/* Your code would be put here */

int main(){
    RankedPair<std::string> P1 { "Pineapple", "Raspberry" };
    RankedPair<std::string> P2 { "Grapefruit", "Raspberry" };
    RankedPair<int> P3 { 6, 10 };
    RankedPair<double> P4 { 1.87, 1.16 };

    std::cout << "P1: smallest = " << P1.smallest();
    std::cout << ", largest = " << P1.largest() << std::endl;
    std::cout << "P2: smallest = " << P2.smallest();
    std::cout << ", largest = " << P2.largest() << std::endl;
    std::cout << "P3: smallest = " << P3.smallest();
    std::cout << ", largest = " << P3.largest() << std::endl;
    std::cout << "P4: smallest = " << P4.smallest();
    std::cout << ", largest = " << P4.largest() << std::endl;
    return 0;
}

The class RankedPair, which must contain (at minimum) a constructor which takes two values, a member function smallest which returns the smaller of the two values from the constructor and a member function largest which returns the larger of the two values from the constructor.

Note that "smaller" in the context of std::string objects refers to dictionary (lexicographical) ordering.

Once it is implemented correctly, the program will generate the following output. 

P1: smallest = Pineapple, largest = Raspberry
P2: smallest = Grapefruit, largest = Raspberry
P3: smallest = 6, largest = 10
P4: smallest = 1.16, largest = 1.87

Write any definition of the RankedPair class such that the complete program compiles and produces the output shown. The RankedPair class should use the < operator to compute the ordering of its elements.

For full marks, your solution must function correctly even if the input values on the previous page are changed.

Hint: You have to use templates (and there is no clever solution that avoids them...).

Solution

template<typename T>
class RankedPair {
    T a, b;
public:
    RankedPair(T x, T y) : a(x), b(y) {}
    T smallest() const { return (a < b) ? a : b; }
    T largest() const { return (a < b) ? b : a; }
};

template<typename T>
void foreach_if( std::vector<T>& vec,
                 std::function< bool(T) > condition,

    for(auto x: vec){

template<typename T>
void foreach_ifnot(std::vector<T>& vec,
                   std::function<bool(T)> cond,
                   std::function<void(T)> F){
    foreach_if(vec, [&](T x){ return !cond(x); }, F);
}

std::vector<int> filter_element(std::vector<int>& vec, int z){
    std::vector<int> out;
    foreach_if(vec, [&](int x){ return x != z; },
                    [&](int x){ out.push_back(x); });
    return out;
}

The Queue class represents a queue data structure where elements are added at one end and removed from the other.

The Queue class must provide the following public member functions:

  • add(x) - Add element x to the queue
  • remove() - Remove and return the first element
  • get(i) - Return element at index i (throws std::out_of_range if invalid)
  • remove_all(x) - Remove all occurrences of x and return count removed
  • size() - Return the number of elements

Constraints:

  • No more than 5 non-constructor public members
  • Any number of constructors and private members allowed

Put your implementation of the Queue class below (continuing on the next page if necessary).

Solution

template<typename T>
class Queue {
    std::vector<T> data;
public:
    void add(const T& x){ data.push_back(x); }
    T remove(){
        T v = data.front();
        data.erase(data.begin());
        return v;
    }
    T get(unsigned i) const{
        if(i >= data.size())
            throw std::out_of_range("Invalid index");
        return data[i];
    }
    unsigned size() const{ return data.size(); }
    unsigned remove_all(const T& x){
        unsigned c = 0;
        auto it = data.begin();
        while(it != data.end())
            if(*it == x){ it = data.erase(it); c++; }
            else ++it;
        return c;
    }
};
