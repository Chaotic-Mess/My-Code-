Time & Random Numbers

Working with time values and generating pseudo-random numbers in C++.

std::time()

Returns the current time as a time_t value representing seconds since the Unix epoch (January 1, 1970).

#include <iostream>
#include <ctime>

int main() {
    std::time_t current_time = std::time(nullptr);
    std::cout << "Seconds since epoch: " << current_time << "\n";
    
    // Convert to readable format
    std::cout << "Current time: " << std::ctime(&current_time);
    return 0;
}
Seconds since epoch: 1702491234 Current time: Fri Dec 13 14:20:34 2025

Key Points:

  • Pass nullptr (or NULL) to get current time
  • Returns a time_t integer value
  • Commonly used to seed random number generators
  • Use std::ctime(&t) to convert to human-readable string
Header: #include <ctime>
Common use: Seeding random generators with std::srand(std::time(nullptr))

std::srand()

Seeds the pseudo-random number generator used by std::rand(). Different seeds produce different sequences of random numbers.

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    // Seed with current time for "true" randomness
    std::srand(std::time(nullptr));
    
    std::cout << "Random number: " << std::rand() << "\n";
    std::cout << "Another random: " << std::rand() << "\n";
    return 0;
}
Random number: 1804289383 Another random: 846930886

Seeding with Fixed Values:

#include <iostream>
#include <cstdlib>

int main() {
    // Same seed = same sequence every time
    std::srand(42);
    
    std::cout << std::rand() << "\n";
    std::cout << std::rand() << "\n";
    return 0;
}
1250203531 1116302336
Important: Only call std::srand() once at the beginning of your program. Calling it multiple times (especially in a loop) will reset the sequence and produce less random results.

Key Points:

  • Must be called before using std::rand() for unpredictable results
  • Using std::time(nullptr) as seed gives different results each run
  • Using a fixed seed (like 42) makes output reproducible (useful for testing)
  • Call only once per program execution

std::rand()

Generates a pseudo-random integer between 0 and RAND_MAX.

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    for (int i = 0; i < 5; i++) {
        std::cout << std::rand() << "\n";
    }
    return 0;
}
1804289383 846930886 1681692777 1714636915 1957747793

Key Points:

  • Returns a value from 0 to RAND_MAX (inclusive)
  • Requires seeding with std::srand() for unpredictability
  • Without seeding, produces the same sequence every run
  • Use modulo operator % to limit range (see examples below)
Header: #include <cstdlib>
Return type: int
Range: [0, RAND_MAX]

RAND_MAX

A constant representing the maximum value std::rand() can return. The exact value is implementation-defined but must be at least 32767.

#include <iostream>
#include <cstdlib>

int main() {
    std::cout << "RAND_MAX on this system: " << RAND_MAX << "\n";
    return 0;
}
RAND_MAX on this system: 2147483647

Common Uses:

  • Checking the range of random numbers
  • Calculating random doubles in range [0, 1]: (double)rand() / RAND_MAX
  • Understanding platform-specific random number limits
Typical value: 2147483647 (2³¹ - 1) on most modern systems
Guaranteed minimum: 32767 (2¹⁵ - 1)

Complete Seeding Pattern

The standard pattern for initializing random numbers at the start of your program.

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    // Seed ONCE at program start
    std::srand(std::time(nullptr));
    
    // Now generate random numbers as needed
    for (int i = 0; i < 3; i++) {
        int random_num = std::rand();
        std::cout << "Random " << i << ": " << random_num << "\n";
    }
    
    return 0;
}
Random 0: 1804289383 Random 1: 846930886 Random 2: 1681692777
DON'T DO THIS:
for (int i = 0; i < 10; i++) {
    std::srand(std::time(nullptr));  // WRONG! Don't reseed in loop
    std::cout << std::rand() << "\n";
}
This will produce the same or very similar numbers because time doesn't change fast enough between iterations.

Generating Random Numbers in a Range

Use the modulo operator to constrain random values to specific ranges.

Random from 0 to N-1

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    // Random number from 0 to 9
    int dice = std::rand() % 10;
    std::cout << "Random 0-9: " << dice << "\n";
    
    return 0;
}
Random 0-9: 7

Random from 1 to N

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    // Simulate rolling a 6-sided die (1-6)
    int dice = (std::rand() % 6) + 1;
    std::cout << "Dice roll: " << dice << "\n";
    
    return 0;
}
Dice roll: 4

Random from Min to Max

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    int min = 10;
    int max = 20;
    
    // Random number from min to max (inclusive)
    int value = min + (std::rand() % (max - min + 1));
    std::cout << "Random 10-20: " << value << "\n";
    
    return 0;
}
Random 10-20: 17
Formula for range [min, max]:
int value = min + (std::rand() % (max - min + 1));

Generating Random Doubles

Generate random floating-point numbers by dividing by RAND_MAX.

Random Double from 0.0 to 1.0

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    // Random double in [0.0, 1.0]
    double random = (double)std::rand() / RAND_MAX;
    std::cout << "Random 0.0-1.0: " << random << "\n";
    
    return 0;
}
Random 0.0-1.0: 0.840188

Random Double in Custom Range

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    double min = 5.0;
    double max = 10.0;
    
    // Random double from min to max
    double random = min + ((double)std::rand() / RAND_MAX) * (max - min);
    std::cout << "Random 5.0-10.0: " << random << "\n";
    
    return 0;
}
Random 5.0-10.0: 7.4201
Formula for range [min, max]:
double value = min + ((double)std::rand() / RAND_MAX) * (max - min);

Monte Carlo Example: Estimating π

#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    
    int inside_circle = 0;
    int total_points = 1000000;
    
    for (int i = 0; i < total_points; i++) {
        // Random point in unit square
        double x = (double)std::rand() / RAND_MAX;
        double y = (double)std::rand() / RAND_MAX;
        
        // Check if inside unit circle
        if (x * x + y * y <= 1.0) {
            inside_circle++;
        }
    }
    
    double pi_estimate = 4.0 * inside_circle / total_points;
    std::cout << "Estimated π: " << pi_estimate << "\n";
    
    return 0;
}
Estimated π: 3.14167

Common Pitfalls & Best Practices

❌ Pitfall 1: Reseeding in Loops

// WRONG: Produces same/similar numbers
for (int i = 0; i < 10; i++) {
    std::srand(std::time(nullptr));
    std::cout << std::rand() << "\n";
}

// CORRECT: Seed once, then generate
std::srand(std::time(nullptr));
for (int i = 0; i < 10; i++) {
    std::cout << std::rand() << "\n";
}

❌ Pitfall 2: Modulo Bias

Using modulo with rand() creates slight bias when RAND_MAX + 1 is not evenly divisible by your range. For most educational purposes this is acceptable, but be aware it exists.

❌ Pitfall 3: Forgetting to Seed

// Without seeding, same sequence every run
int main() {
    // No srand() call!
    std::cout << std::rand() << "\n";  // Always same value
    return 0;
}

✅ Best Practices

  • Call std::srand(std::time(nullptr)) once at program start
  • Include <cstdlib> for rand/srand, <ctime> for time
  • For modern C++ (C++11+), consider using <random> library instead
  • Test with fixed seeds (e.g., srand(42)) for reproducible debugging
  • Cast to double when dividing by RAND_MAX
Modern Alternative: C++11 introduced the <random> library with better random number generation. However, rand() and srand() are still commonly used in educational settings and legacy code.
