Math Operations

Arithmetic, functions from <cmath>, and numeric utilities.

Basic arithmetic

Integer and floating-point operations.

#include <iostream>

int main() {
    int a = 10;
    int b = 3;
    std::cout << "Add: " << (a + b) << "\n";
    std::cout << "Subtract: " << (a - b) << "\n";
    std::cout << "Multiply: " << (a * b) << "\n";
    std::cout << "Divide: " << (a / b) << "\n";
    std::cout << "Modulo: " << (a % b) << "\n";
}
Add: 13 Subtract: 7 Multiply: 30 Divide: 3 Modulo: 1
Integer division truncates (no remainder). Use double for exact division: 10.0 / 3 ≈ 3.333

Power, square root, and exponents

Use <cmath> for advanced operations.

#include <iostream>
#include <cmath>

int main() {
    double x = 16.0;
    std::cout << "sqrt(16): " << std::sqrt(x) << "\n";
    std::cout << "pow(2, 3): " << std::pow(2, 3) << "\n";
    std::cout << "abs(-5): " << std::abs(-5) << "\n";
}
sqrt(16): 4 pow(2, 3): 8 abs(-5): 5
  • std::sqrt(x) returns the square root.
  • std::pow(base, exp) raises base to the power of exp.
  • std::abs() works for both int and double versions.

Trigonometry and logarithms

More advanced math functions.

#include <iostream>
#include <cmath>

int main() {
    double pi = 3.14159;
    std::cout << "sin(pi/2): " << std::sin(pi / 2) << "\n";
    std::cout << "cos(0): " << std::cos(0) << "\n";
    std::cout << "log(10): " << std::log10(10) << "\n";
}
sin(pi/2): 1 cos(0): 1 log(10): 1
  • std::sin(), std::cos(), std::tan() work with radians.
  • std::log() is natural log; std::log10() is base-10.

Rounding and truncation

Convert floating-point to integer values.

#include <iostream>
#include <cmath>

int main() {
    double x = 3.7;
    std::cout << "Original: " << x << "\n";
    std::cout << "floor: " << std::floor(x) << "\n";
    std::cout << "ceil: " << std::ceil(x) << "\n";
    std::cout << "round: " << std::round(x) << "\n";
}
Original: 3.7 floor: 3 ceil: 4 round: 4
  • std::floor() rounds down; std::ceil() rounds up.
  • std::round() rounds to the nearest integer.

Min and max

Find minimum and maximum values efficiently.

#include <iostream>
#include <algorithm>

int main() {
    int a = 5;
    int b = 12;
    std::cout << "Min: " << std::min(a, b) << "\n";
    std::cout << "Max: " << std::max(a, b) << "\n";
}
Min: 5 Max: 12
  • std::min() and std::max() are in <algorithm>.
  • Both work with any comparable types (int, double, string, etc.).

Random numbers (<random>)

Generate pseudo-random values.

#include <iostream>
#include <random>

int main() {
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(1, 10);
    
    for (int i = 0; i < 3; ++i) {
        std::cout << dis(gen) << "\n";
    }
}
7 3 9
  • std::mt19937 is a Mersenne Twister generator (better than rand()).
  • std::uniform_int_distribution produces uniform random integers in a range.
  • Example: 05.1-random.cpp
