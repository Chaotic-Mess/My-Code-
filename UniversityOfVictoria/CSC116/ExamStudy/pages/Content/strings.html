Strings

std::string fundamentals, operations, and common patterns.

Fundamentals FAQ

  • Header? <string> for std::string; <iostream> for printing.
  • .size() vs .length()? Same result; use either.
  • operator[] vs .at()? [] is unchecked (UB on bad index). .at() throws std::out_of_range.
  • Append choices? +=, push_back(char), or .append() for strings.
  • Substring params? substr(pos, len) returns at most len chars starting at pos.
  • Find return? Position index or std::string::npos if not found.
  • Conversions? std::to_string (number → string), std::stoi/stol/stod (string → number, throw on bad input).
  • C-string view? .c_str() gives const char* for C APIs/printf.
  • Comparison? Uses lexicographic order; case-sensitive.
  • Iteration safety? Range-for is safe; avoid mutating size while iterating unless using indices carefully.

std::string basics

Declare, initialize, and concatenate strings.

#include <iostream>
#include <string>

int main() {
    std::string greeting = "Hello";
    std::string name = "Ada";
    std::string message = greeting + ", " + name;
    std::cout << message << "\n";
}
Hello, Ada
  • Use + to concatenate strings.
  • Strings are mutable; you can modify them after creation.

Indexing and .at()

Access individual characters safely and unsafely.

#include <iostream>
#include <string>

int main() {
    std::string word = "code";
    std::cout << word[0] << "\n";
    std::cout << word.at(1) << "\n";
}
c o
[] is faster but does not check bounds. .at() throws std::out_of_range if the index is invalid.
  • Use .at() when you need safety.
  • Use [] when performance is critical and you know the index is valid.

Length and iteration

Measure strings and loop through characters.

#include <iostream>
#include <string>

int main() {
    std::string text = "hello";
    std::cout << "Length: " << text.length() << "\n";
    for (char c : text) {
        std::cout << c << "\n";
    }
}
Length: 5 h e l l o
  • Use .length() or .size() (both do the same thing).
  • Range-based for loops are the cleanest way to iterate.
  • Example: 14-string_to_lower.cpp

Comparison and substring

Compare strings and extract parts.

#include <iostream>
#include <string>

int main() {
    std::string a = "apple";
    std::string b = "apple";
    std::string c = "banana";
    std::cout << (a == b ? "equal" : "not equal") << "\n";
    std::cout << (a < c ? "a before c" : "c before a") << "\n";
    std::cout << a.substr(0, 3) << "\n";
}
equal a before c app
  • Use == and < for comparison (lexicographic).
  • .substr(pos, len) returns a substring starting at pos for len characters.
  • Example: 15-longest_word.cpp

find() and replace()

Search for substrings and make replacements.

#include <iostream>
#include <string>

int main() {
    std::string text = "hello world";
    std::string::size_type pos = text.find("world");
    if (pos != std::string::npos) {
        std::cout << "Found at: " << pos << "\n";
    }
}
Found at: 6
  • .find() returns the position of the first occurrence, or std::string::npos if not found.
  • Use .replace() to modify parts of a string.

Vectors of strings

Store and manipulate collections of strings.

#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words = {"apple", "banana", "cherry"};
    for (const auto& w : words) {
        std::cout << w << "\n";
    }
}
apple banana cherry
  • Combine std::vector and std::string for flexible text data.
