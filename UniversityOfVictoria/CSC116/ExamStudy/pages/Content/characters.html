Characters

char type, character functions, and ASCII operations.

Fundamentals FAQ

  • Header? <cctype> for character tests and case conversion; <string> if working with std::string.
  • Why std::? All cctype functions live in std; call std::isalpha, std::tolower, etc.
  • Signed/unsigned chars? Cast to unsigned char before passing to std::tolower/isalpha if the value might be negative.
  • Return values? Classification functions return non-zero for true, zero for false; case conversion returns the converted char (as int).
  • ASCII vs Unicode? Examples assume ASCII. These functions are locale-aware but not full Unicode processing.
  • Escape characters? Common ones: '\n' newline, '\t' tab, '\\' backslash, '\'' single quote.
  • Iterating strings? Use range-for; avoid modifying string size while iterating unless using indices.

char type basics

Store and manipulate individual characters.

#include <iostream>

int main() {
    char letter = 'A';
    char digit = '5';
    char special = '!';
    std::cout << letter << digit << special << "\n";
}
A5!
  • Single quotes 'A' denote a char; double quotes "A" denote a string.
  • Chars are integers under the hood; you can perform arithmetic on them.

ASCII values and arithmetic

Understand character encoding and offset operations.

#include <iostream>

int main() {
    char c = 'A';
    std::cout << "ASCII of 'A': " << (int)c << "\n";
    std::cout << "Next char: " << (c + 1) << "\n";
    std::cout << "Difference 'Z' - 'A': " << ('Z' - 'A') << "\n";
}
ASCII of 'A': 65 Next char: B Difference 'Z' - 'A': 25
Casting a char to int reveals its ASCII value. Arithmetic on chars works because they are just integers.
  • Use this to find character offsets (e.g., distance between 'A' and 'Z').

Character classification (<cctype>)

Test properties of characters.

#include <iostream>
#include <cctype>

int main() {
    char c = '5';
    std::cout << (std::isdigit(c) ? "digit" : "not digit") << "\n";
    std::cout << (std::isalpha('A') ? "letter" : "not letter") << "\n";
    std::cout << (std::isspace(' ') ? "space" : "not space") << "\n";
}
digit letter space
  • std::isdigit(), std::isalpha(), std::isalnum(), std::isspace(), etc.
  • Returns non-zero (true) or zero (false).

Case conversion

Convert between uppercase and lowercase.

#include <iostream>
#include <cctype>

int main() {
    char lower = 'a';
    char upper = 'Z';
    std::cout << std::toupper(lower) << "\n";
    std::cout << std::tolower(upper) << "\n";
}
A z
  • std::toupper() and std::tolower() return the converted char.
  • Non-letter characters are returned unchanged.
  • Example: 14-string_to_lower.cpp

Iterating over string characters

Process each character in a string individually.

#include <iostream>
#include <string>
#include <cctype>

int main() {
    std::string text = "HeLLo";
    for (char c : text) {
        std::cout << std::tolower(c);
    }
    std::cout << "\n";
}
hello
  • Range-based for loops let you modify or inspect each character.
  • You can also use indexed loops: for (int i = 0; i < text.length(); i++)
