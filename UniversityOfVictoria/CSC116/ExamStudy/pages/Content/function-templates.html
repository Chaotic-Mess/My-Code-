Function Templates

Write generic functions that work for multiple types.

Overview

Function templates enable type-independent algorithms. The compiler generates concrete functions for each used type at call sites.

Template Function Syntax

template<typename T>
T maxOf(const T& a, const T& b) {
    return (a > b) ? a : b;
}

std::cout << maxOf(3, 7) << '\n';      // 7
std::cout << maxOf("aa", "bb") << '\n'; // uses const char* comparison (lexicographic by pointer) — prefer std::string
std::cout << maxOf(std::string("aa"), std::string("bb")) << '\n'; // bb
Important: Operators used in templates (like >) must be valid for the type.

Type Deduction

template<typename T>
T add(T a, T b) { return a + b; }

auto i = add(2, 3);          // T deduced as int
auto d = add(2.5, 1.5);    // T deduced as double
auto s = add(std::string("a"), std::string("b")); // std::string
Tip: You can specify template arguments explicitly: add<double>(2, 3).

Constraints (Simple Patterns)

While C++20 concepts provide formal constraints, you can still use simple SFINAE-like patterns or rely on documentation and static_asserts for CSC116-level topics.

template<typename T>
T multiply(T a, T b) {
    static_assert(!std::is_same_v, "multiply requires numeric types");
    return a * b;
}

Overloads & Specializations

template<typename T>
T minOf(const T& a, const T& b) { return (a < b) ? a : b; }

// Overload for const char*
const char* minOf(const char* a, const char* b) {
    return std::strcmp(a, b) < 0 ? a : b;
}

// Full specialization example
template<>
std::string minOf(const std::string& a, const std::string& b) {
    return (a.size() < b.size()) ? a : b; // different criteria
}

Fundamentals FAQ

Where should I place template function definitions?

In headers or the same translation unit where they are used, so the compiler can instantiate them when needed.

What if type deduction fails?

You can provide explicit template arguments: func<Type>(args...).

Can function templates be overloaded?

Yes. You can provide non-template overloads, template overloads, and even specializations for specific types.
