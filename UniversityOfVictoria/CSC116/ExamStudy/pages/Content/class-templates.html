Class Templates

Write type-generic classes in C++ using templates.

Overview

Class templates allow you to define a class once and use it with different types. They are fundamental for containers like std::vector and utilities like std::pair.

Template Syntax

template<typename T>
class Box {
private:
    T value;
public:
    Box(const T& v) : value(v) {}
    T get() const { return value; }
    void set(const T& v) { value = v; }
};
Note: template<typename T> and template<class T> are equivalent in this context.

Member Functions

template<typename T>
class Accumulator {
    T total{}; 
public:
    void add(const T& x) { total += x; }
    T sum() const { return total; }
};

Accumulator<int> a1;
a1.add(3);
a1.add(4); 
std::cout << a1.sum() << '\n'; // 7
Important: Operators used inside templates (like +=) must be defined for the type parameter.

Partial and Full Specialization

Specialization lets you customize behavior for specific types.

template<typename T>
class Printer {
public:
    void print(const T& v) { std::cout << v << '\n'; }
};

// Full specialization for bool
template<>
class Printer<bool> {
public:
    void print(bool v) { std::cout << (v ? "true" : "false") << '\n'; }
};
Tip: Partial specialization applies to class templates, not function templates.

Usage Examples

Box<int> bi(42);
std::cout << bi.get() << '\n';

Box<std::string> bs("hello");
bs.set("world");
std::cout << bs.get() << '\n';

Fundamentals FAQ

Where are template definitions placed?

Template definitions must be visible at the point of instantiation. Commonly, you keep template class definitions and member function implementations in headers (or the same header) so the compiler can generate code for each used type.

Can I use multiple type parameters?

Yes. Use commas inside the angle brackets, e.g., template<typename K, typename V>.

What is template<> with empty angle brackets?

That denotes a full specialization of a template for a specific set of template arguments.
