Vectors

Dynamic arrays, manipulation, iteration, and algorithms.

Fundamentals FAQ

  • Header? <vector> for std::vector; <algorithm>/<numeric> for algorithms.
  • Default state? Empty vector has size 0, capacity 0.
  • Adding elements? push_back amortized O(1); may reallocate and invalidate pointers/iterators/references.
  • Bounds checks? .at() throws on bad index; [] is unchecked.
  • Iteration choices? Range-for for read-only; use auto& to modify in place; const vectors give const references.
  • reserve vs resize? reserve changes capacity only; resize changes size (and value-initializes new elements).
  • erase/insert cost? O(n) and they invalidate iterators at/after the point of change.
  • front/back safety? Calling on an empty vector is UB; check .empty() first.
  • Capacity growth? Implementation-defined; typically geometric (about 1.5–2x).

Vector basics

Declaration, initialization, and basic operations.

#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    std::cout << "Empty vector size: " << v.size() << "\n";
    
    v.push_back(10);
    v.push_back(20);
    v.push_back(30);
    std::cout << "After 3 push_backs: " << v.size() << "\n";
}
Empty vector size: 0 After 3 push_backs: 3
  • push_back() adds an element to the end.
  • size() returns the current number of elements.
Vectors automatically manage memory. They grow as needed when elements are added.
push_back(x) x is the value to add. Not the amount you are pushing back.

Accessing elements

Indexing, .at(), and iteration.

#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};
    
    std::cout << "v[0]: " << v[0] << "\n";
    std::cout << "v.at(1): " << v.at(1) << "\n";
    std::cout << "v.front(): " << v.front() << "\n";
    std::cout << "v.back(): " << v.back() << "\n";
}
v[0]: 10 v.at(1): 20 v.front(): 10 v.back(): 30
.at() throws an exception if index is out of bounds. [] does not check; use it when you're certain the index is valid.

Range-based for loop

The modern way to iterate over vectors.

#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {5, 10, 15};
    
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
5 10 15
  • for (int x : v) copies each element; use int& to modify in-place.
  • for (const int& x : v) for read-only access to avoid copies.

Adding and removing elements

push_back(), pop_back(), insert(), and erase().

#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};
    
    v.pop_back();
    std::cout << "After pop_back: ";
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
    
    v.erase(v.begin() + 1);
    std::cout << "After erase(1): ";
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
}
After pop_back: 10 20 After erase(1): 10
  • pop_back() removes the last element.
  • erase(iterator) removes at a specific position.

Capacity vs. size

Understanding memory allocation.

#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    
    std::cout << "Initial size: " << v.size() 
              << ", capacity: " << v.capacity() << "\n";
    
    for (int i = 0; i < 5; ++i) {
        v.push_back(i);
        std::cout << "size: " << v.size() 
                  << ", capacity: " << v.capacity() << "\n";
    }
}
Initial size: 0, capacity: 0 size: 1, capacity: 1 size: 2, capacity: 2 size: 3, capacity: 4 size: 4, capacity: 4 size: 5, capacity: 8
size() = number of elements; capacity() = allocated memory. Vectors double capacity when needed to avoid frequent allocations.

Iterators

Pointers-like objects for traversing containers.

#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};
    
    for (auto it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << "\n";
}
10 20 30
  • .begin() points to the first element; .end() points past the last.
  • Dereference with *it to access the element.
  • Prefer range-based for loops unless you need the iterator itself.

Algorithms: find, count, and sort

Common operations from <algorithm>.

#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5};
    
    auto it = std::find(v.begin(), v.end(), 4);
    std::cout << "Found 4 at index: " 
              << std::distance(v.begin(), it) << "\n";
    
    int cnt = std::count(v.begin(), v.end(), 1);
    std::cout << "Count of 1: " << cnt << "\n";
    
    std::sort(v.begin(), v.end());
    std::cout << "Sorted: ";
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
}
Found 4 at index: 2 Count of 1: 2 Sorted: 1 1 3 4 5
  • std::find() returns an iterator to the first match, or .end() if not found.
  • std::count() returns how many elements match a value.
  • std::sort() sorts in ascending order by default.

Accumulate and reduce

Sum or combine all elements.

#include <iostream>
#include <vector>
#include <numeric>

int main() {
    std::vector<int> v = {1, 2, 3, 4};
    
    int sum = std::accumulate(v.begin(), v.end(), 0);
    std::cout << "Sum: " << sum << "\n";
    
    int product = std::accumulate(v.begin(), v.end(), 1,
        [](int a, int b) { return a * b; });
    std::cout << "Product: " << product << "\n";
}
Sum: 10 Product: 24
  • std::accumulate() is in <numeric>.
  • Third argument is the initial value (0 for sum, 1 for product).
  • Optional fourth argument is a custom binary operation (here, a lambda for multiplication).
  • Example: 108-accumulate.cpp

Vector of vectors (2D arrays)

Nested vectors for matrix-like structures.

#include <iostream>
#include <vector>

int main() {
    std::vector<std::vector<int>> matrix(
        2, std::vector<int>(3, 0)
    );
    
    matrix[0][0] = 5;
    matrix[1][2] = 9;
    
    for (int i = 0; i < 2; ++i) {
        for (int j = 0; j < 3; ++j) {
            std::cout << matrix[i][j] << " ";
        }
        std::cout << "\n";
    }
}
5 0 0 0 0 9
  • std::vector<std::vector<int>> creates a 2D vector.
  • Constructor argument: rows=2, columns=3, initialized to 0.

Common mistakes and performance

Tips for efficient vector usage.

// AVOID: Expensive erase in a loop
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it % 2 == 0) {
        v.erase(it);  // O(n) for each erase!
    }
}

// PREFER: Use remove-erase idiom
v.erase(
    std::remove_if(v.begin(), v.end(),
        [](int x) { return x % 2 == 0; }),
    v.end()
);
Tip: erase() in a loop is O(n²). Use the remove-erase idiom for O(n) complexity. Reserve capacity upfront with v.reserve(n) if you know the final size.
