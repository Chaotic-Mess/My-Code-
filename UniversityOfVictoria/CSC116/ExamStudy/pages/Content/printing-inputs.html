Fundamentals FAQ

  • Do I need std::? Yes, unless you using namespace std; (not recommended for headers). Prefix I/O names with std::.
  • Headers? <iostream> for cout/cin, <string> for std::string, <cstdio> for printf, <limits> for numeric_limits.
  • std::endl vs "\n"? endl adds newline and flushes (slower if overused). "\n" just adds newline.
  • Why flush? To force buffered output out (e.g., progress updates). Avoid flushing every line if performance matters.
  • std::cin >> behavior? Skips leading whitespace and stops at next whitespace. Leaves the delimiter (newline) in the buffer.
  • Why does getline get skipped? A prior cin >> left a newline; call cin.ignore(...) first.
  • Recover from bad input? cin.clear(); cin.ignore(numeric_limits<streamsize>::max(), '\n');
  • printf format basics? Use matching specifiers: %d int, %f/%.2f double, %s C-string. Pass primitive values or c_str() from std::string.
  • Tabs vs spaces? "\t" inserts a tab; for aligned tables prefer iomanip or fixed widths.
  • EOF loop pattern? while (std::cin >> x) { ... } ends when input closes or parse fails.

std::cout << ...

Stream insertion prints values; chain multiple items and mix literals with variables.

#include <iostream>

int main() {
    int x = 42;
    int px = 3;
    int py = 4;
    std::cout << "Value: " << x << "\n";
    std::cout << "Point(" << px << ", " << py << ")\n";
}
Value: 42 Point(3, 4)
  • Prefer "\n" when you do not need to flush; use std::endl only when you must flush.
  • Use chained prints for table rows: one line per record.
  • Examples: 01-hello.cpp, 111-lambda3.cpp
"\n" adds a newline without flushing. std::endl adds a newline and flushes immediately, which costs more when you do it on every line.

Use case: formatted table row

#include <iostream>
#include <string>

int main() {
    int id = 17;
    std::string name = "Avery";
    int score = 95;
    std::cout << id << "\t" << name << "\t" << score << "\n";
}
17 Avery 95

Use tabs or spaces for simple columns without iomanip.

std::endl

Writes a newline and flushes the stream. Flushing every line can slow long prints.

#include <iostream>

int main() {
    std::cout << "Completed batch" << std::endl; // forces flush
}
Completed batch
  • Use when you need timely output (e.g., progress lines).
  • Examples: 111-lambda3.cpp, 108-accumulate.cpp

std::cin >> ...

Formatted extraction; skips leading whitespace. Stops at the next whitespace boundary.

#include <iostream>
#include <limits>

int main() {
    int x;
    int sum = 0;
    while (std::cin >> x && x != -1) {
        sum += x;
    }
    std::cout << "Sum: " << sum << "\n";
}
Input: 5 7 -1 Output: Sum: 12
  • Examples: 03-numeric_input.cpp, 43-read_one_number.cpp

Use case: validate numeric input

#include <iostream>
#include <limits>

int main() {
    int v;
    if (!(std::cin >> v)) {
        std::cin.clear();
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
        std::cout << "Invalid number\n";
    }
}
Input: hello Output: Invalid number

std::getline(std::cin, ...)

Reads an entire line including spaces. Always consume leftover newlines before calling after formatted input.

#include <iostream>
#include <string>

int main() {
    std::string name;
    std::getline(std::cin, name);
    std::cout << "Hello, " << name << "!\n";
}
Input: Ada Lovelace Output: Hello, Ada Lovelace!
  • Example: 11-getline.cpp

printf (C-style)

Formatted C I/O; useful when you need classic format strings.

#include <cstdio>

int main() {
    int count = 5;
    double average = 72.3456;
    printf("%d %0.2f\n", count, average);
}
5 72.35

Be mindful of matching format specifiers to argument types.
