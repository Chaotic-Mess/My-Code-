String Constructors & Methods

Deep dive into std::string initialization, manipulation, and conversion.

Related Topics: See Strings Basics for fundamentals, and Classes for constructor mechanics.

String Constructors

std::string is a class with multiple constructors. Understanding which constructor is called determines how your string is initialized.

Default Constructor

// Creates an empty string
std::string s1;
std::string s2{};  // same, but explicit

std::cout << s1.size() << '\n';  // 0

String Literal Constructor

// Constructs from C-style string (char array)
std::string s3 = "hello";
std::string s4{"world"};
std::string s5("C++");

std::cout << s3 << '\n';  // hello

Copy Constructor

// Creates a copy of another string
std::string original = "data";
std::string copy1 = original;
std::string copy2{original};

copy1[0] = 'D';
std::cout << original << '\n';  // "data" (unchanged)
std::cout << copy1 << '\n';     // "Data" (independent)

Substring Constructor

// Construct from a portion of another string
std::string base = "programming";
std::string sub1(base, 0, 7);  // "program" (start at 0, length 7)
std::string sub2(base, 3, 4);  // "gram"    (start at 3, length 4)

std::cout << sub1 << '\n';  // program

Fill Constructor

// Construct string with n copies of a character
std::string stars(10, '*');  // "**********"
std::string dashes(5, '-'); // "-----"

std::cout << stars << '\n';
Common Mistake: 
std::string s(5);  // ERROR: no matching constructor
std::string s(5, 'x');  // OK: "xxxxx"
You must provide a character when using the fill constructor.

Size & Length

Both methods return the number of characters in the string. They are identical.

std::string name = "Alice";

std::cout << name.size() << '\n';    // 5
std::cout << name.length() << '\n'; // 5 (same result)

// Common usage in loops
for (size_t i = 0; i < name.size(); ++i) {
    std::cout << name[i] << ' ';
}
// Output: A l i c e
Why two identical methods? size() is consistent with other STL containers like vector. length() exists for familiarity with other string libraries. Use whichever you prefer.

Empty Check

std::string s1;
std::string s2 = "data";

if (s1.empty()) {
    std::cout << "s1 is empty\n";  // prints
}

if (s2.size() == 0) {  // same as empty(), but less clear
    std::cout << "s2 is empty\n";
}

Accessing Elements

Operator[] (Unchecked Access)

Fast, but no bounds checking. Accessing out-of-range is undefined behavior.

std::string word = "code";

std::cout << word[0] << '\n';  // 'c'
std::cout << word[3] << '\n';  // 'e'

word[0] = 'C';  // modify: "Code"

// DANGER: undefined behavior (no error thrown)
char bad = word[10];  // may crash, may return garbage

.at() (Checked Access)

Slightly slower, but throws exception if index is out of range.

std::string word = "safe";

std::cout << word.at(0) << '\n';  // 's'

try {
    char bad = word.at(10);  // throws std::out_of_range
} catch (const std::out_of_range& e) {
    std::cout << "Error: " << e.what() << '\n';
}

operator[]

  • ✅ Faster
  • ✅ Use in loops when bounds are known
  • ⚠️ No error checking
  • ⚠️ Undefined behavior if out of range

.at()

  • ✅ Safe
  • ✅ Throws exception on invalid index
  • ⚠️ Slightly slower (bounds check)
  • ⚠️ Use when index comes from user input

Front & Back

std::string s = "hello";

std::cout << s.front() << '\n';  // 'h' (same as s[0])
std::cout << s.back() << '\n';   // 'o' (same as s[s.size()-1])

Modifying Strings

Operator+= (Append)

Adds content to the end of a string.

std::string msg = "Hello";

msg += " world";  // append string literal
std::cout << msg << '\n';  // "Hello world"

msg += '!';  // append single character
std::cout << msg << '\n';  // "Hello world!"

std::string name = " Alice";
msg += name;  // append another string
std::cout << msg << '\n';  // "Hello world! Alice"

Operator+ (Concatenation)

Creates a new string by combining existing ones.

std::string first = "C++";
std::string second = " Programming";

std::string full = first + second;
std::cout << full << '\n';  // "C++ Programming"

// Chaining
std::string sentence = "I " + "love " + first + "!";
// ERROR: can't add two literals directly

// Fix: ensure at least one operand is std::string
std::string sentence = std::string{"I"} + " love " + first + "!";
std::cout << sentence << '\n';  // "I love C++!"
Common Error: 
std::string s = "hello" + " world";  // ERROR!
You cannot add two C-string literals. At least one operand must be std::string.

.push_back() (Add Single Character)

std::string s = "abc";

s.push_back('d');
s.push_back('e');

std::cout << s << '\n';  // "abcde"

// Common pattern: building strings in loops
std::string vowels;
for (char c : {'a', 'e', 'i', 'o', 'u'}) {
    vowels.push_back(c);
}
std::cout << vowels << '\n';  // "aeiou"

Other Useful Modifiers

std::string s = "hello";

// .append() - same as +=, but more flexible
s.append(" world");

// .insert() - insert at position
s.insert(5, ",");  // "hello, world"

// .erase() - remove characters
s.erase(5, 1);  // remove 1 char at position 5: "hello world"

// .clear() - empty the string
s.clear();
std::cout << s.size() << '\n';  // 0

Conversions

String to Number: std::stoi()

Converts a string to an integer. Throws std::invalid_argument if conversion fails.

#include <string>
#include <iostream>

std::string num_str = "42";
int value = std::stoi(num_str);

std::cout << value + 10 << '\n';  // 52

// Handles leading/trailing whitespace
int v2 = std::stoi("  123  ");  // 123

// Stops at first non-digit
int v3 = std::stoi("99bottles");  // 99

try {
    int bad = std::stoi("hello");  // throws std::invalid_argument
} catch (const std::invalid_argument& e) {
    std::cout << "Invalid number\n";
}

Related Functions

  • std::stol() → long
  • std::stoll() → long long
  • std::stof() → float
  • std::stod() → double

Number to String: std::to_string()

Converts numeric types to strings.

#include <string>

int age = 25;
std::string msg = "You are " + std::to_string(age) + " years old.";
std::cout << msg << '\n';  // "You are 25 years old."

double pi = 3.14159;
std::string pi_str = std::to_string(pi);
std::cout << pi_str << '\n';  // "3.141590" (default precision)

Character Case: std::tolower() & std::toupper()

These work on individual characters, not strings. They're in <cctype>. 

#include <cctype>
#include <string>

char upper = 'A';
char lower = std::tolower(upper);
std::cout << lower << '\n';  // 'a'

// Convert entire string to lowercase
std::string name = "ALICE";
for (char& c : name) {
    c = std::tolower(c);
}
std::cout << name << '\n';  // "alice"

// Or using a loop with index
std::string word = "hello";
for (size_t i = 0; i < word.size(); ++i) {
    word[i] = std::toupper(word[i]);
}
std::cout << word << '\n';  // "HELLO"
Common Mistake: std::tolower() and std::toupper() return int, not char. Assign back to char to use as a character.

Fundamentals FAQ

Why does std::string have both size() and length()?

Both return the same value. size() exists for consistency with other STL containers (like std::vector), while length() is more intuitive for strings. Use whichever you prefer.

What's the difference between [] and .at()?

operator[] is faster but has no bounds checking—accessing an invalid index causes undefined behavior. .at() performs bounds checking and throws std::out_of_range if the index is invalid. Use [] in performance-critical loops where you know the index is valid, and .at() when the index comes from user input or is uncertain.

Can I add two string literals with +?

No. "hello" + "world" will cause a compile error because both operands are C-style strings (char arrays), not std::string objects. At least one operand must be std::string: 

std::string s = std::string{"hello"} + " world";  // OK
What happens if std::stoi() receives non-numeric input?

It throws std::invalid_argument. Always use a try-catch block when converting user-provided strings:

try {
    int n = std::stoi(user_input);
} catch (const std::invalid_argument&) {
    std::cout << "Not a valid number\n";
}
How do I convert an entire string to lowercase?

std::tolower() works on individual characters, so loop through the string:

std::string s = "HELLO";
for (char& c : s) {
    c = std::tolower(c);
}
// s is now "hello"

The reference (&) is important—it modifies the original string.

What's the difference between += and .push_back()?

operator+= can append strings, string literals, or single characters. .push_back() only appends a single character. For single characters, they're equivalent: 

s += 'x';  // OK
s.push_back('x');  // also OK
Why does my string have extra digits after using std::to_string() on a double?

std::to_string() uses default precision (typically 6 decimal places):

std::to_string(3.14);  // "3.140000"

To control precision, use std::ostringstream with std::fixed and std::setprecision.

Can I compare strings with ==?

Yes! std::string overloads ==, !=, <, >, etc., for lexicographic comparison: 

std::string a = "apple";
std::string b = "banana";

if (a < b) {  // true (lexicographically)
    std::cout << "a comes before b\n";
}
How do I check if a string is empty?

Use .empty(), which is clearer than checking size:

if (s.empty()) {  // preferred
    std::cout << "String is empty\n";
}

if (s.size() == 0) {  // also works, but less idiomatic
    std::cout << "String is empty\n";
}
What's the difference between a C-string (char*) and std::string?

C-strings are null-terminated character arrays with manual memory management and limited operations. std::string is a class that manages memory automatically and provides rich functionality (concatenation, searching, resizing, etc.). Always prefer std::string in modern C++.
