📦 GitHub Directory Downloader

Fetch and download the contents of any GitHub directory as a zip file — directly from your browser.

What It Does

This utility helps you grab an entire GitHub folder (without cloning the whole repository). It uses the official GitHub REST API to fetch files, then packages them into a single, ready-to-use zip archive.

  • Download any public GitHub folder directly
  • Supports private repos with personal access tokens
  • Runs entirely in your browser — no installation needed

Try It Out

Paste a GitHub directory link below. Example:

https://github.com/owner/repo/tree/main/path/to/folder

Tips & Notes

  • If your link starts with /tree/main/ or /blob/main/, this tool will parse it automatically.
  • Large folders may take longer to process — you’ll see progress logs below.
  • For private repositories, generate a personal access token from GitHub Settings → Developer Settings → Tokens.
