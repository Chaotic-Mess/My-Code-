GitHub Directory Downloader

Download any GitHub directory as a single, neatly packaged ZIP file — without cloning the entire repository.

What It Does

This tool uses the GitHub REST API to recursively fetch files from any folder in a repository. It then bundles everything into a ZIP archive — all in your browser. No installs, no servers, no rate limits (beyond GitHub’s own).

  • Recursively downloads all subfolders
  • Parallel file downloads for speed
  • Supports private repos using a GitHub access token
  • Entirely client-side — nothing leaves your browser

Try It Out

Paste the link to a GitHub directory (not a single file).

https://github.com/owner/repo/tree/main/folder

Notes & Tips

  • Works with URLs in the form /tree/main/ or any branch name.
  • Private repositories require a valid GitHub Personal Access Token.
  • Your token is used only for authentication — it never leaves your browser.
  • Progress logs will appear below as files are downloaded.

How to Get a GitHub Token (For Private Repos)

To download from private repositories, you'll need a GitHub Personal Access Token. Don't worry — it's quick and easy to create one!

Step-by-Step Guide:

  1. Go to GitHub Settings → Developer Settings → Personal Access Tokens
  2. Click "Generate new token" → Choose "Tokens (classic)"
  3. Give your token a descriptive name (e.g., "Directory Downloader")
  4. Set an expiration date (or choose "No expiration" if you want it permanent)
  5. Under Select scopes, check the repo checkbox
    • This grants read access to your private repositories
    • For public repos only, you don't need any scopes selected
  6. Scroll down and click "Generate token"
  7. ⚠️ Copy the token immediately — you won't be able to see it again!
  8. Paste the token into the "GitHub token" field above

🔒 Security Note:

Your token is processed entirely in your browser and is never sent to any server other than GitHub's API. Treat it like a password — don't share it publicly or commit it to repositories.

Alternative: Fine-Grained Tokens

GitHub also offers fine-grained personal access tokens with more precise permissions:

  1. Follow the same path but choose "Fine-grained tokens"
  2. Select specific repositories you want to grant access to
  3. Under Repository permissions, set Contents to "Read-only"
  4. Generate and copy your token

This approach is more secure as it limits access to only the repositories you specify.
