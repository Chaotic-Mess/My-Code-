Brightspace Scraper

A one-click bookmarklet to download your entire Brightspace course — PDFs, videos, slides, and more.

What It Does

This tiny JavaScript tool runs directly inside your browser. It uses the same API calls your Brightspace page already makes — so there’s no login or setup required.

  • Automatically fetches all accessible course materials
  • Downloads videos, PDFs, slides, and other files
  • Organizes everything neatly into folders
  • Offers checkboxes to choose file types (.pdf, .mp4, .docx…)

How to Use It

  1. Drag the button below to your bookmarks bar.
  2. Go to your Brightspace course homepage.
  3. Click the bookmark — the overlay will appear automatically.

or drag this → Brightspace Scraper

If you see a warning about mixed content or blocked scripts, open your course in a new tab and retry.
