Brightspace — One-click PDF downloader

How it works: open your Brightspace course page (e.g. https://bright.uvic.ca/d2l/home/426051) and while logged in click the bookmarklet below (or install the userscript). The scraper will gather downloadable files (PDFs and other common extensions), build a ZIP, and prompt you to download it.

Drag: Download Brightspace Files

Alternative

If you prefer, install the userscript (Tampermonkey): paste the code from script.js into a new Tampermonkey script and enable it for https://bright.uvic.ca/*.

Notes

  • You must be logged in to Brightspace when running the bookmarklet/userscript.
  • Depending on course structure, the script finds links by common file-extension matches and Brightspace file URLs.
