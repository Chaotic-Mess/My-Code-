Brightspace Scraper

A one-click downloader for your Brightspace course files.
Works right from the browser — no extensions, no setup. Not doing any malpractices. This simply takes the downloads and files you can normally download and ORGANISES them by module / existing folder structure. Something the original system doesn't do. Many Brightspace Courses don't have a Table of Contents, and if they do, the download button simply downloads all the mismatched ugly files. This fixes that. You're welcome.

How it works

  • Scans your course’s Table of Contents
  • Finds all downloadable files (PDFs, docs, slides, etc.)
  • Zips everything neatly by module
  • Lets you toggle file types (PDF, MP4, DOCX...)
