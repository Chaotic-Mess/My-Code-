## 📂 Repository Overview

This repository is organized into several main categories:

### 🛠️ **Helpful Utilities**
Tools designed to make everyday tasks easier:
- **Brightspace Scraper** - Automated content extraction from learning management systems
- **Directory Downloader** - Batch download files from web directories
- **YouTube Downloader** - Full-stack Flask application for downloading YouTube content

### 🤖 **AI & Machine Learning**
Exploring the frontiers of artificial intelligence:
- **ARES AI V1** - Custom neural network with training pipeline and HuggingFace integration
- **ARES AI V2** - Enhanced architecture with improved testing
- **ARES AI V3** - Advanced agent system with web interface and interactive shell

### 🎮 **Interactive Showcases**
Visual demonstrations and interactive experiences:
- **3D Solar System** - WebGL-powered planetary visualization
- **Farm Drone Game** - Browser-based game with custom parsing engine

### ⚙️ **Algorithm Systems**
Visualizations of computational concepts:
- **Pathfinding System** - A*, Dijkstra, BFS visualizations
- **Sorting Visualizer** - Real-time algorithm comparison
- **Video to ASCII** - Real-time video-to-ASCII art conversion

### 🌐 **Web Development**
Full-featured web applications:
- **Aeon** - Modern web app with modular architecture
- **Banking Website** - Comprehensive platform with transactions, wallets, and more

### 🎓 **University Work**
Academic projects from University of Victoria:
- **CSC 111** - Fundamentals of Programming
- **CSC 116** - Fundamentals of Programming II
