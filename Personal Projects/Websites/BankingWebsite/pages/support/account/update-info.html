Update Account Information

Keep your LUNA account details current and accurate

What You Can Update

Verification Required

Some information updates may require additional verification for security purposes

  • Contact Information (email, phone, address)
  • Personal Details (name change, ID updates)
  • Employment and Income Information
  • Communication Preferences

Update Process

  1. Log in to your secure account dashboard
  2. Navigate to Profile Settings
  3. Select information to update
  4. Provide required documentation
  5. Verify changes via 2FA

Required Documentation

Document Guidelines

All documents must be clear, current, and in digital format (PDF, JPG, PNG)

  • Government-issued ID for name changes
  • Proof of address (utility bill, lease)
  • Marriage certificate or court order for legal changes
  • Employment verification for income updates
