Password Reset Process

Security Notice

For your security, the reset process requires multi-factor authentication

  1. Enter your account email address
  2. Complete biometric verification (if enabled)
  3. Receive a quantum-encrypted reset code
  4. Create a new secure password

Password Requirements

  • Minimum 12 characters length
  • Mix of uppercase and lowercase letters
  • At least one number and special character
  • Cannot be similar to previous passwords

Additional Security Options

Enhanced Protection

Consider enabling additional security features after resetting your password

  • Enable two-factor authentication
  • Set up biometric verification
  • Configure login notifications
  • Review connected devices
