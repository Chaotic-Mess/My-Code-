🤖 Drone API Reference

Movement Functions

void moveForward()

Moves the drone one cell forward in its current direction.

void turnRight()

Rotates the drone 90 degrees clockwise.

void turnLeft()

Rotates the drone 90 degrees counter-clockwise.

Sensing Functions

CellState scan()

Returns the state of the current cell. Returns: EMPTY, PLANTED, GROWING, GROWN, or OBSTACLE.

CellState scanAhead()

Returns the state of the cell ahead without moving.

Action Functions

void plant()

Plants a seed in the current cell (must be EMPTY).

void harvest()

Harvests crops from the current cell (must be GROWN).

void water()

Waters the crop in current cell to speed up growth.

Control Flow

void loop() { ... }

Main function that runs repeatedly. Put your automation logic here.

if (condition) { ... }

Standard C++ conditional statement.

while (condition) { ... }

Standard C++ loop statement.

Constants

EMPTY, PLANTED, GROWING, GROWN, OBSTACLE

Cell state constants for use with scan() functions.
